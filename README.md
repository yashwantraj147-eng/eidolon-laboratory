## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
git clone https://github.com/yashwantraj147-eng/eidolon-laboratory.git
cd eidolon-laboratory
npm install
```

### Running Locally (Web)
```bash
npm run dev
```
Navigate to `http://localhost:5173`.

### Running Desktop Application (Electron)
```bash
npm run electron
```

### Running Unit Tests
```bash
npm test
```

### Production Build
```bash
npm run build
```
